# ✅ To-Do App

A simple and interactive **To-Do Application** built using **React.js** that allows users to manage their daily tasks efficiently. Users can add, search, edit, complete, and delete tasks with an easy-to-use interface.

---

## 📌 Project Overview

The To-Do App helps users organize their tasks and track progress. It provides essential task management features such as adding new tasks, editing existing ones, searching tasks, marking tasks as completed using checkboxes, and deleting tasks when they are no longer needed.

---

## ✨ Features

- ➕ **Add Task**
  - Add new tasks to the list

- 🔍 **Search Task**
  - Search tasks by name or keyword

- ✏️ **Edit Task**
  - Update existing tasks

- ☑️ **Complete Task**
  - Mark tasks as completed using a checkbox

- 🗑️ **Delete Task**
  - Remove tasks from the list

- 📱 **Responsive UI**
  - Works smoothly on all screen sizes

---

## 🛠️ Technologies Used

- **Frontend:** React.js  
- **Styling:** CSS / Bootstrap / Tailwind CSS  
- **State Management:** React Hooks  
- **Version Control:** Git & GitHub
